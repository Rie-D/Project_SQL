## Built a Tableau dashboard to visualize key business metrics:
- Monthly Revenue Trend (line chart)
- Top 10 Products by Revenue (bar chart)
- Top 10 Customers by Revenue (bar chart)
- Average Order Value (KPI)

Filters allow interactive exploration by Country, Category, and Return Flag.
